## Domain

Hostel Management → Mess Management

## Problem Context

Mess operations at Hostel D (Neeram Hall) serving approximately 800 students across three meals daily are handled through three disconnected channels — the menu via WhatsApp, rebates on paper forms and feedback through a QR-linked web form. These channels share no common data store. So, requests cannot be tracked and feedback cannot be linked to the meal it concerns.

## Proposed System

A single role-based application in which students view the daily menu, rate meals, submit complaints, apply for rebates and vote in menu polls. The mess committee publishes and revises the menu, acts on feedback and manages complaints. The warden approves rebates. The contractor receives consolidated reports.
